Data Architecture (Critical)

Primary Table: Olist_Marketing_Funnel (= looker_studio_master.csv, 8,000 rows, 1 row = 1 MQL)

Star Schema: Orders, Order_Items, Order_Reviews, Sellers, Products, Category_Translation

Relationship NOTE: Olist_Marketing_Funnel은 star schema와 직접 관계 없음. Page 1&4는 이 테이블 단독 사용. Page 2&3은 star schema 사용.

Scatter Chart 주의: Scatter의 "Values" = 점의 grain(카테고리). X/Y Axis = measure. MQL[origin] 절대 사용 금지 (관계 없음) → Olist_Marketing_Funnel[origin] 사용

COUNT 정책: Olist_Marketing_Funnel은 row = unique MQL이므로 COUNTROWS = DISTINCTCOUNT(mql_id). Order_Items는 주문당 복수 행 → 주문 수 = DISTINCTCOUNT(order_id)

Power BI Field Well Reference (Chart Type별)
각 차트 유형의 정확한 필드 well 명칭

Scatter Chart

Values점의 grain (카테고리 필드). 빠지면 1점으로 집계됨!
X AxisMeasure (숫자)
Y AxisMeasure (숫자)
Legend색 구분 (카테고리)
SizeBubble 크기 (measure)

Clustered Bar / 100% Stacked Bar

Y-axis카테고리 (바 레이블)
X-axisMeasure (바 길이/값)
Legend색 분리 (series)
Small mult.소규모 반복 차트
"Values" 필드 없음! X-axis가 값 역할.

Matrix

Rows행 카테고리
Columns열 카테고리
Values셀 값 (measure)

Funnel / Waterfall / Card

Funnel: Category + Values
Waterfall: Category + Values (+ Y-axis Breakdown optional)
Card: Fields (measure 하나)
Table: Columns (모든 필드 나열)
